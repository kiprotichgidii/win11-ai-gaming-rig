# Product Requirements Document (PRD)

## 1. Vision & Goals
Enable high-performance personal workstations to act as 24/7 internal AI infrastructure, low-latency remote game streaming hosts, and virtualization labs without hardware exclusivity or OS partitioning.

## 2. Target Users & Use Cases
- **Software Engineers & AI Practitioners**: Running local coding models (Qwen, Llama) connected to JetBrains/Android Studio and web interfaces.
- **Gamers & Content Creators**: Streaming games to living room TVs or laptops with native controller support.
- **Infrastructure Engineers**: Running multi-node test VMs on Hyper-V with true LAN IP access.

## 3. Success Metrics
- Provisioning time under 15 minutes (excluding download times).
- Sub-5ms streaming latency over 1Gbps LAN.
- Zero manual network adapter bridging or port configuration required by the operator.
